# BBY-03 Climate Food Vulnerability App

## 📁 Project Structure

- frontend → React + Vite
- backend → Node + Express

---

## 🚀 Setup Instructions

### 1. Clone repo

git clone <repo-url>
cd 2800-202610-BBY03

---

### 2. Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on: http://localhost:5173

---

### 3. Run Backend

```bash
cd backend
npm install
npm run dev
```

Backend runs on: http://localhost:3000
